ISGS-Reason: Instance-Semantic Embedded 3D Gaussian Splatting and Novel-View Reasoning for Comprehensive Scene Understanding

Xihan Wang, Tianji Jiang, Jiadong Tang, Yu Gao
Beijing Institute of Technology
TMM
Paper Supplementary Code arXiv

Abstract

Scene understanding requires the joint modeling of semantic representations and spatial structures. Recent advances in 3D Gaussian Splatting (3DGS) have enabled semantic features to be embedded into Gaussian primitives. However, existing methods still suffer from imbalanced instance-semantic integration and insufficient query-relevant visual evidence. To address these limitations, we propose ISGS-Reason, a unified framework that embeds instance-aware semantic features and performs query-guided novel-view reasoning for 3D segmentation and visual grounding. First, IARM estimates point-level feature reliability from entropy-based confidence and intra-instance consistency, while CAAR adaptively balances these two cues for semantic refinement. The refined semantic features provide reliable candidate regions for subsequent reasoning. Second, we propose a query-guided novel-view reasoning strategy to provide sufficient visual evidence for visual grounding. Extensive experiments demonstrate that ISGS-Reason consistently outperforms state-of-the-art methods on both 3D segmentation and visual grounding.

Method Overview and Qualitative Results

Given posed RGB-D images and an initial point cloud, the Instance--Semantic Initialization module assigns instance labels and aggregates multi-view semantic features to 3DGS primitives. Then, the Instance-Aware Reliability Modeling module evaluates reliability from entropy-based confidence and intra-instance consistency, while the Correlation-Aware Adaptive Refinement module adaptively balances these complementary cues to refine semantic distributions and features. With the refined semantic representation, the Query-Guided Novel-View Reasoning module localizes candidate regions, samples spherical views, and performs visual reasoning. Ultimately, the model locates the query-related target through back-projection.

Qualitative 3D semantic segmentation results. ISGS-Reason refines noisy point-level semantic features through instance-aware reliability modeling and correlation-aware adaptive refinement, leading to more coherent object-level predictions and improved boundary quality.

Open-vocabulary segmentation results on LERF scenes. The refined instance-semantic representation improves category consistency and suppresses noisy semantic assignments.

Query-guided 3D visual grounding results. The proposed reasoning strategy selects informative views and localizes the target object according to the query.

Spatial-relation grounding examples. By combining refined 3D semantics with novel-view reasoning, ISGS-Reason can distinguish query-related targets from distractors.
